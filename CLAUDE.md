# Oqu Dana Tiin (kashgari-mobile)

Expo SDK 57 / RN 0.86 app for Kazakh language learning. Roles: student, teacher, parent, principal. Backend: kashgari-api (GraphQL, `https://gql.danatiin.kashgari.kz/`). Visual source of truth: the Donatien prototype (HTML), matched nearly 1:1.

## Layout
- `src/app/` expo-router routes, one-line re-exports only. Role areas: `student/`, `teacher/`, `parent/`, `principal/`, each with `(tabs)/` and pushed pages. Root `_layout.tsx` guards each area with `Stack.Protected` by the active profile's role.
- `src/features/<feature>/` screens, hooks, `gql.ts` documents, feature components, `__tests__/`. Group by feature, not by role. Shared class/student pieces live in `features/classes`, report parts in `features/reports`, student assignment mapping in `features/assignments`.
- `src/ui/` dumb primitives measured from the prototype (Text, Button, Card, ListRow, SegmentedTabs, StatusMark, TabScreen, BackBar, Dialog, Sheet, Icon...). `src/ui/icon.tsx` holds the prototype's own icon set.
- `src/lib/` Apollo client (auth headers, token refresh via `new-authorization`, sign-out on AUTHENTICATION_ERROR), i18n, env, storage.
- `src/global.css` design tokens (colours, fonts, radii, shadows) and utilities (`sheen`, `bg-workspace`, `bg-dock`). Change colours there only.
- `src/locales/{kk,ru,en}/<feature>.json` auto-registered; use `t('<feature>.key')`. Kazakh Latin (`kk-Latn`) is generated by transliteration; learning content goes through `useContentText()`.
- `graphql/schema/*.gql` snapshot of kashgari-api (`bun run schema:sync` copies it from `../kashgari-api`), then `bun run codegen` → `src/graphql/`.

## Session
`features/auth/session.ts` (zustand, persisted in SecureStore / localStorage on web): one phone or social login yields credentials per content language database (kk/ru/en/fr) and a list of role profiles; `useProfile()` is the active one. The `danatiin-language` header follows the profile's language, independent of the UI language.

## Commands
- `bun run check` lint (oxlint) + typecheck + jest.
- `bun run codegen` after changing any `gql()` document.
- `bun run web:mock` web dev server answering GraphQL from `src/dev/mocks/<OperationName>.ts` (dev only, never in release builds). Use it to compare screens with the prototype.
- No native builds from CI agents; OTA via `.github/workflows/update.yml` on push to `updates`.

## Rules
- Use the tokens and `src/ui` primitives; no hardcoded UI strings; no wrapper components without a reason.
- Features the API cannot serve yet render `<NotReady />` from `@/ui/feedback` instead of fake data.
- Dropped on purpose: whiteboard, OCR, PDF export, battleships, infinite runner, physical activity, screenshot blocking.
